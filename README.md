# 책장 (BookReader)

Claude AI가 쓴 교양서를 읽는 Windows 데스크톱 앱입니다. 읽다가 궁금한 곳은 바로 Claude에게 물어볼 수 있어요. 개인이 만든 무료 앱이에요.

## 들어 있는 책
| 책 | 내용 |
|---|---|
| **과학의 역사 1** — 하늘의 질서에서 생명의 기원까지 (7장) | 고대 그리스, 이슬람 세계와 중세, 코페르니쿠스·케플러·갈릴레오·뉴턴, 화학혁명, 다윈 |
| **과학의 역사 2** — 보이지 않는 힘에서 우주의 기원까지 (7장) | 전기와 자기, 열과 에너지, 세균과 근대 의학, 양자역학, 상대성이론, DNA, 빅뱅 |
| **경제는 어떻게 움직이나** (12장) | 선택과 시장, 시장의 실패, 돈과 은행, 금리, 물가, 경기와 대공황, 금융 위기, 무역과 환율, 성장과 불평등, 오늘의 한국 경제 |

책은 Claude가 사실 확인을 하며 썼지만, 틀리거나 지나치게 단순화한 곳이 있을 수 있어요. 이상한 곳은 글을 드래그해서 바로 물어보세요. 경제 책은 특정 투자 상품을 권하지 않아요.

## 기능
- **실제 책처럼 읽기**: 쪽 단위로 넘기고(←/→, 휠, 쪽 가장자리 클릭), 넓은 창에서는 두 쪽을 펼쳐 보여 줘요. 쪽 번호와 머리글이 있어요
- **목차·책갈피**: 장과 절로 바로 가고(T), 🔖로 책갈피를 꽂아요(B)
- **보기 설정**: 글자 크기, 명조/고딕, 줄 간격, 한 쪽/두 쪽, 테마(밝게·세피아·다크 등)
- **읽던 곳 기억**: 앱을 다시 켜면 마지막에 읽던 책의 그 쪽으로 열려요
- **Claude에게 묻기**: 본문을 드래그해서 '💬 이 부분 질문' → 다시 설명 / 더 쉽게 / 예시로 / 직접 질문. Claude는 지금 보고 있는 쪽을 함께 보고 답하고, 필요하면 책의 다른 장을 찾아 읽어요. 대화는 책마다 따로 저장돼요
- **구글 계정 동기화(선택)**: 여러 PC에서 읽던 곳·책갈피·질문 대화를 이어 가기

## 받기

**[최신 버전 내려받기 (BookReader.exe)](https://github.com/Leopard7711/BookReader-releases/releases/latest/download/BookReader.exe)**

- Windows 10/11 (64비트). 설치 없이 exe 하나로 실행돼요.
- 새 버전이 나오면 앱이 켜질 때 알아서 업데이트해요.
- **이 페이지(github.com/Leopard7711/BookReader-releases)에서만 받으세요.** 다른 곳에 올라온 파일은 변조됐을 수 있어요.

### "Windows의 PC 보호" 창이 뜨면

코드 서명 인증서가 없는 개인 앱이라 처음 실행할 때 Windows가 경고를 띄워요.
**추가 정보** → **실행**을 누르면 됩니다. 백신이 막으면 이 페이지에서 받은 파일인지 확인한 뒤 예외로 허용해 주세요.

## 책 읽기는 무료, 묻기는 API 키가 필요해요

책을 읽는 데는 아무것도 필요 없어요. **Claude에게 묻기**를 쓰려면 AI 사용료를 **본인의 Anthropic(또는 OpenAI·Google) 계정에서 직접** 내는 API 키가 필요해요(개발자에게 가는 돈은 없어요). 처음 질문할 때 키를 넣는 창이 떠요.

- **Claude (기본)**: https://console.anthropic.com 가입 → **Billing**에서 크레딧 충전 → **API Keys** → **Create Key**로 키(`sk-ant-…`)를 만들어 복사
- **GPT**: https://platform.openai.com 에서 키(`sk-…`)를 만들어 복사
- **Gemini**: https://aistudio.google.com 에서 키를 만들어 복사

기본 모델은 Claude Sonnet이고, 질문 한 번에 대략 1~3센트예요(질문 길이와 고른 모델에 따라 달라져요). 설정에서 모델을 바꿀 수 있어요.

## 기록이 저장되는 곳
- 읽던 곳, 책갈피, 질문 대화: `%APPDATA%\BookReader` (설정 → 데이터 폴더 열기)
- API 키와 로그인 정보는 이 PC에만 저장되고 동기화하지 않아요.
